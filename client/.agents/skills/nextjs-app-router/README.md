# Next.js App Router skill

Reusable AI coding skill for Next.js 16 and newer App Router projects.

## Canonical installation

```text
.agents/skills/nextjs-app-router/
```

## Claude Code

Copy the same directory to:

```text
.claude/skills/nextjs-app-router/
```

## Project-specific skills

Load separate project skills for authentication and authorization, Cache Components policy, internationalization, data access, styling and design systems, testing, and deployment.

## Recommended repository rule

Copy `templates/AGENTS.nextjs.md` into the project's root `AGENTS.md`, preserving custom instructions outside the managed markers.
