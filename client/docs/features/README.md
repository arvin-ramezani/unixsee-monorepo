Create a feature directory when behavior cannot be understood reliably from code and tests alone. A feature specification should define the problem, requirements, non-goals, constraints, edge cases, and acceptance criteria without duplicating system architecture.

The existing custom-scrollbar document is an implementation-specific reference. Update it with the corresponding component behavior when scrollbar ownership changes.
