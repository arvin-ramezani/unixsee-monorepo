## Light-Mode Image Palette

| Role                  | Color     |
| --------------------- | --------- |
| Primary structure     | `#132439` |
| Secondary structure   | `#244A74` |
| Strong blue accent    | `#39577C` |
| Sky-blue highlight    | `#9FDCFF` |
| Light blue detail     | `#DCE6F2` |
| Mint accent           | `#56F39B` |
| Warm secondary accent | `#CFA562` |
| Near-white highlight  | `#F9FAFB` |

Recommended image ratio: 55% navy, 25% medium blue, 12% sky blue, and 8% mint or gold accent.

## Dark-Mode Image Palette

| Role                    | Color     |
| ----------------------- | --------- |
| Darkest structure       | `#11161E` |
| Primary blue surface    | `#1D395B` |
| Secondary blue          | `#244A74` |
| Bright blue detail      | `#6D92BF` |
| Sky-blue highlight      | `#9FDCFF` |
| Light foreground detail | `#F0F2F4` |
| Mint accent             | `#62C37A` |
| Warm secondary accent   | `#E6AC3D` |

Recommended image ratio: 45% deep blue, 25% medium blue, 18% sky blue or near-white, and 12% mint or gold accent.

For large icons, avoid `#132439` as the dominant dark-mode color because it can disappear against the `#101B29` page background. Use `#1D395B` as the dark-mode base, reserve `#132439` for internal depth, keep transparent backgrounds, and use mint or gold as small semantic accents.
